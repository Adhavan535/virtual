6) FILE TRANSFER BETWEEN VIRTUAL MACHINES – 


METHOD 1: VIRTUALBOX SHARED FOLDER


1. In VirtualBox:
   Devices -> Insert Guest Additions CD Image
   Settings -> Shared Folders -> Add Windows folder
   Select Auto-mount and save.

2. Check mounted folders:
   ls /media

3. Add current user to the shared-folder group:
   sudo usermod -aG vboxsf $USER

4. Reboot:
   sudo reboot

5. List shared-folder files:
   ls /media/sf_VMShared

6. Copy a file into the shared folder:
   cp VM1.txt /media/sf_VMShared/

7. Verify the copied file:
   ls /media/sf_VMShared
